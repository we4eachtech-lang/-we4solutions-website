Free publishing option:
1. Create a free GitHub account.
2. Create a public repository named `we4solutions`.
3. Upload `index.html`.
4. In Settings → Pages, choose Deploy from branch → main → /root.
5. GitHub will provide a free `github.io` address.
6. Your GoDaddy domain `we4solutions.in` can then be connected to the GitHub Pages site using DNS records.
